Yavrumun Özel Günü — Mobil Deneme

1. ZIP dosyasını tamamen çıkartın.
2. index.html dosyasını Chrome ile açın.
3. Açılıştaki “Sürprizi Aç” butonuna basınca müzik başlar.
4. Tarayıcı müziği engellerse sağ üstteki ♫ veya oynat düğmesine bir kez dokunun.

Mobil görünüm için bilgisayarda Chrome > F12 > telefon simgesini açabilirsiniz.
